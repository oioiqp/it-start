## 🌟 Ключевые возможности проекта

### 1. Единая кодовая база для Веб-версии и Telegram Mini App
- В `index.html` подключен официальный скрипт `<script src="https://telegram.org/js/telegram-web-app.js"></script>`.
- При открытии внутри Telegram автоматически вызываются `WebApp.ready()` и `WebApp.expand()`, считываются данные пользователя (`user.id`, `username`, `first_name`) с тактильным откликом (HapticFeedback).
- `chat_id` автоматически подставляется в форму подписки на вакансии.
- В обычном браузере отображается статус веб-режима с кнопками быстрого перехода к боту и автоопределением Chat ID.

### 2. Реальные Telegram-уведомления (Киллер-фича)
- **Безопасное локальное хранение Bot Token:** секретный токен от `@BotFather` не коммитится в публичный репозиторий, а вводится и сохраняется в защищенном `localStorage` браузера во вкладке «Telegram & Парсер».
- **Тестовое уведомление:** мгновенная проверка доставки сообщения от бота пользователю с inline-кнопкой открытия WebApp (`reply_markup`).
- **Симулятор парсера каналов (@tbank_start, @yandex_intern, @ozon_tech_career и др.):** публикация вакансии в 1 клик — сохранение в базу **Supabase** (`public.internships`) и отправка пуш-уведомлений в Telegram всем подписчикам с подходящим стеком.

### 3. База знаний по 6 главным направлениям разработки
1. **Frontend-разработка:** Core (сеть, CRP, JS Event Loop, TS) + ветки React, Angular, Vue.js.
2. **Backend-разработка:** Core (REST, ACID, PostgreSQL, Docker, Redis) + ветки Python, Go (Golang), Java, Node.js.
3. **Mobile-разработка:** Core (MVVM, Clean Arch, Main Thread) + ветки Android (Kotlin), iOS (Swift), Flutter.
4. **Data Science, ML & Аналитика:** Core (тервер, матстат, SQL) + ветки ML Engineer, Data Analyst.
5. **QA (Тестирование ПО):** Core (теория, тест-дизайн, Postman, SQL) + ветки Manual QA, QA Automation.
6. **DevOps & Cloud:** Core (Linux, Bash, Nginx) + ветки CI/CD & Docker, Kubernetes & IaC.

### 4. Агрегатор стажировок с расчетом готовности
- 18 предзаполненных актуальных стажировок (Т-Банк, Яндекс, Сбер, Ozon Tech, VK, Avito, Лаборатория Касперского, Альфа-Банк, Контур).
- Фильтры по направлению, ветке, формату (Удаленно/Гибрид/Офис) и источнику.
- **Модальное окно «План подготовки к стажировке»:** динамический расчет процента готовности студента к вакансии (`%`), список этапов роадмапа и персональный список профильных вопросов к собеседованию с возможностью отмечать их прямо в окне.

### 5. Тренажёр 55+ вопросов к собеседованиям
- База из 56 детализированных вопросов с развернутыми ответами, примерами кода и ключевыми тезисами.
- Два режима: **«Список с ответами (Аккордеон)»** и **«Тренажёр флеш-карточек (Симуляция собеседования)»**.
- Разделы «Изучено» и «Нужно повторить».

## 🛠️ Запуск и разработка

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера с HMR
npm run dev

# Запуск автоматических тестов (Vitest)
npm run test

# Сборка продакшн-бандла для GitHub Pages
npm run build
```

Автоматический деплой настроен через GitHub Actions (`.github/workflows/deploy.yml`) при пуше в ветку `main`.
