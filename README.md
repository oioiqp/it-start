## 🌟 Ключевые возможности проекта

### 1. Мультиплатформенность: Web, Telegram Mini App и VK Mini App
- В `index.html` подключены официальные библиотеки интеграции.
- При открытии в Telegram вызываются `WebApp.ready()`, `WebApp.expand()` и считываются данные пользователя с тактильным откликом.
- При открытии в VK (VK Mini App) автоматически активируется адаптер `VK Bridge` и парсятся параметры запуска (`vk_user_id`, `vk_platform`, `vk_app_id`).
- В обычном браузере отображается адаптивный интерфейс с возможностью тестирования отправки пушей в Telegram и ВКонтакте.

### 2. Боты для Telegram (@IT_start_izh_bot) и ВКонтакте (VK Bots Long Poll)
- **Единая база вакансий:** боты подключены к единой таблице Supabase (`public.internships`) и общему модулю парсинга карьерных сайтов/каналов (Т-Банк, Контур, Directum, Т1, Яндекс, Ozon, Сбер, Авито, VK).
- **Интерактивные команды:** `/start` (приветствие и клавиатура), `/vacancies` (фильтр по стекам), `/companies` (обзор работодателей), `/roadmaps` (роадмапы), `/questions` (вопросы), `/subscribe` (подписка на пуши), `/status` (аптайм и парсер), `/help`.
- **Умный поиск по компаниям:** достаточно отправить боту название компании («директум», «контур», «тбанк», «т1», «яндекс»), чтобы сразу получить список актуальных стажировок.
- **Безопасное локальное хранение токенов:** секретные токены ботов не коммитятся в репозиторий, а настраиваются через переменные окружения сервера или вводятся в защищенное `localStorage` браузера во вкладке «Боты & Парсер».

### 3. База знаний по 6 главным направлениям разработки
1. **Frontend-разработка:** Core (сеть, CRP, JS Event Loop, TS) + ветки React, Angular, Vue.js.
2. **Backend-разработка:** Core (REST, ACID, PostgreSQL, Docker, Redis) + ветки Python, Go (Golang), Java, Node.js.
3. **Mobile-разработка:** Core (MVVM, Clean Arch, Main Thread) + ветки Android (Kotlin), iOS (Swift), Flutter.
4. **Data Science, ML & Аналитика:** Core (тервер, матстат, SQL) + ветки ML Engineer, Data Analyst.
5. **QA (Тестирование ПО):** Core (теория, тест-дизайн, Postman, SQL) + ветки Manual QA, QA Automation.
6. **DevOps & Cloud:** Core (Linux, Bash, Nginx) + ветки CI/CD & Docker, Kubernetes & IaC.

### 4. Агрегатор стажировок с расчетом готовности
- Актуальные оплачиваемые стажировки ведущих работодателей.
- Фильтры по направлению, ветке, формату (Удаленно/Гибрид/Офис), источнику и компаниям.
- **Модальное окно «План подготовки к стажировке»:** динамический расчет процента готовности студента (`%`), список тем роадмапа и персональные вопросы к собеседованию.

### 5. Тренажёр 55+ вопросов к собеседованиям
- Детализированные вопросы с разбором ответов, антипаттернов и критериев собеседования.
- Режимы «Список с ответами» и «Тренажёр флеш-карточек (Симуляция собеседования)».

## 🛠️ Запуск и разработка

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера с HMR
npm run dev

# Запуск автоматических тестов (Vitest)
npm run test

# Сборка продакшн-бандла для GitHub Pages
npm run build

# Запуск Telegram-бота и HTTP Health Check сервера
TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН" npm run bot

# Запуск VK-бота сообщества ВКонтакте
VK_BOT_TOKEN="ВАШ_КЛЮЧ_ГРУППЫ" npm run bot:vk

# Одновременный запуск обоих ботов (Telegram + VK)
npm run bot:all
```

Подробная инструкция по настройке и деплою ботов 24/7 находится в [bot/README.md](file:///bot/README.md).
