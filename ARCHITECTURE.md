# 🏛️ Архитектура платформы «IT-Старт»

## 1. Общее описание системы

Платформа **«IT-Старт»** — мультиплатформенный сервис для поиска стажировок и Junior-вакансий, развития профессиональных навыков по интерактивным роадмапам и подготовки к техническим собеседованиям.

Архитектура системы включает следующие ключевые компоненты:
- **Single Page Application (SPA) фронтенд**: единое веб-приложение, работающее в браузере на десктопных и мобильных устройствах, а также как **Telegram Mini App** внутри мессенджера (ВКонтакте Mini App на данный момент под вопросом и пока не используется).
- **Серверный бэкенд на Render.com (Node.js)**: круглосуточный Web Service, объединяющий работу ботов (Telegram и ВКонтакте), модуль автоматического мониторинга вакансий и легковесный HTTP Health Check сервер.
- **Облачная база данных Supabase (PostgreSQL)**: централизованное хранилище вакансий, подписок и пользовательского прогресса с многоуровневым in-memory fallback.
- **Мониторинг работодателей**: модуль фонового сканирования каналов и сайтов карьерных программ с автоматической классификацией по направлениям/стеку и рассылкой пуш-уведомлений подписчикам.
- **Система автопробуждения (Keep-Alive через UptimeRobot)**: механизм предотвращения засыпания бесплатного контейнера Render.

## 2. Стек технологий

| Направление | Технологии | Назначение |
|---|---|---|
| **Фронтенд** | TypeScript, React, Vite, Tailwind CSS | Быстрый SPA-интерфейс, статическая типизация, мгновенная сборка и адаптивная стилизация |
| **Бэкенд-скрипты** | Node.js (ES Modules) | Фоновый парсер, обработка данных, планировщик задач и HTTP Health Check сервер |
| **Боты** | Telegram Bot API, VK Bots Long Poll API | Взаимодействие с пользователями в Telegram и ВКонтакте, отправка пуш-уведомлений |
| **База данных** | Supabase (PostgreSQL) | Облачная реляционная база данных с REST API (`@supabase/supabase-js`) |
| **Тестирование** | Vitest | Автоматизированное модульное и интеграционное тестирование (45 тестов) |
| **Линтинг** | Oxlint | Статический анализ и быстрая проверка качества кода |

## 3. База данных (Supabase PostgreSQL)

Централизованное хранение данных организовано в 3 таблицах схемы `public`:

1. **`public.internships`**
   - **Назначение**: Хранение каталога актуальных стажировок и вакансий для начинающих специалистов.
   - **Что хранит**: Идентификатор (`id`), название вакансии (`title`), компания (`company`), направление (`direction_id`: frontend, backend, mobile, data_science, qa, devops), специализация (`sub_track_id`), уровень зарплаты (`salary`), формат работы (`format`: удаленно / офис / гибрид), локация, теги стека (`tags`), прямая ссылка на страницу отклика (`apply_url`), источник (`source_channel`), дата публикации.

2. **`public.tg_subscriptions`**
   - **Назначение**: Хранение профилей подписчиков на автоматические пуш-уведомления о новых вакансиях.
   - **Что хранит**: Идентификатор диалога (`chat_id` в Telegram или `peer_id` в VK), имя пользователя (`username` / `first_name`), список выбранных направлений (`directions`), дату подписки и статус активности (`is_active`).

3. **`public.user_progress`**
   - **Назначение**: Сохранение личного прогресса подготовки студента к собеседованиям.
   - **Что хранит**: `user_id`, списки пройденных тем роадмапов (`completed_topics`), подтем (`completed_subtopics`), изученных вопросов тренажёра (`completed_questions`) и вопросов, помеченных для повторения (`repeat_questions`).

**Отказоустойчивость базы данных**: Если облачный сервис Supabase временно недоступен или не настроен ключ доступа, приложение и боты бесшовно переключаются на встроенное in-memory/localStorage хранилище. Сервис продолжает отдавать предустановленные данные без сбоев.

## 4. Хостинг, CI/CD и деплой

- **GitHub (контроль версий и CI/CD)**: Единый репозиторий проекта. Автоматический запуск сборки и тестов при каждом пуше.
- **GitHub Pages (Хостинг фронтенда)**:
  - Бесплатный статический хостинг для клиентского SPA.
  - Деплой выполняется автоматически через GitHub Actions при обновлении ветки `main`.
  - Публичный адрес: `https://oioiqp.github.io/it-start/`.
  - Маршрутизация для SPA обеспечивается генерацией `404.html` на этапе пост-сборки (`scripts/postbuild.cjs`).
- **Render.com (Хостинг бэкенда)**:
  - Развертывание в виде Node.js Web Service на бесплатном тарифе.
  - Запускает процесс `node bot/bot.mjs --all`, в котором круглосуточно работают боты, HTTP-сервер и планировщик парсера.
  - Публичный URL: `https://it-start-bot.onrender.com`.

## 5. Telegram-бот и Telegram Mini App

- **Telegram-бот (@IT_start_izh_bot)**:
  - Работает через официальный Telegram Bot API методом Long Polling (без необходимости открывать входящие вебхук-порты).
  - Предоставляет команды: `/start` (приветствие, навигация, кнопка запуска WebApp), `/vacancies` (просмотр стажировок с фильтром по стеку), `/companies`, `/roadmaps`, `/questions`, `/status`, `/scan`, `/help`.
  - Рассылает персонализированные пуш-уведомления подписчикам сразу при обнаружении новых позиций.
- **Telegram Mini App**:
  - Фронтенд открывается непосредственно внутри Telegram как веб-приложение.
  - Автоматически синхронизирует тему оформления с клиентом Telegram (тёмная/светлая), использует тактильный отклик (Haptic Feedback) и подставляет профиль пользователя для персональной аналитики готовности.

## 6. ВКонтакте-бот

- **VK-бот (Сообщество ID: 242573933)**:
  - Работает через Bots Long Poll API (VK API v5.199) с автоматической активацией событий сообщений (`message_new`, `message_event`).
  - Поддерживает команды меню: «Стажировки», «Компании», «Роадмапы», «Вопросы», «Подписка», «Сайт», «Статус», «Помощь», естественные приветствия («Здравствуйте», «Привет») и моментальный отклик на inline-события (`message_event`).
  - **Контекстная цифровая навигация**: распознает выбор цифрами в зависимости от текущего экрана (в меню стажировок: 1–6 — фильтр по направлениям Frontend..DevOps; в компаниях: 1–9 — работодатели; в главном меню: 1–8 — разделы платформы).
  - Распознает оба формата структуры событий VK API (`object.message` и прямой `object`), включая нормализацию вложенных и дважды сериализованных строк payload.
  - **Автоматический обход ошибок клавиатур (коды 912, 100)**: если в веб-настройках группы ВКонтакте отключена опция «Возможности ботов» или тип клавиатуры временно ограничен, бот перехватывает ошибку, преобразует кнопки в аккуратное нумерованное текстовое меню и повторно отправляет сообщение в текстовом режиме. Сообщение гарантированно доставляется пользователю.
- **ВКонтакте Mini App**: пока не работает и находится под вопросом, поэтому в текущую архитектуру платформы не включается.

## 7. Мониторинг вакансий и парсер

Модуль мониторинга в `bot/bot.mjs` отвечает за непрерывную актуализацию базы стажировок:
1. **Параллельный сбор данных**: Периодическое сканирование публичных каналов и веб-страниц карьерных программ.
2. **Извлечение сущностей и классификация**: Текстовый анализатор ищет ключевые термины технологий и автоматически относит позицию к соответствующему направлению (Frontend, Backend, Mobile, Data Science, QA, DevOps) и конкретному технологическому стеку (React, Python, Go, Java, Docker и др.).
3. **Дедупликация**: Формирование составного хеш-ключа (компания + заголовок + источник), исключающее повторное добавление одной и той же позиции.
4. **Пакетное сохранение в Supabase**: Новые уникальные записи сохраняются в таблицу `public.internships`.
5. **Рассылка уведомлений**: Подписчики в Telegram и VK получают мгновенные пуш-сообщения со ссылкой на отклик и персональными рекомендациями тем для подготовки.

## 8. Автопробуждение (Keep-Alive через UptimeRobot)

### Как мы обошли ограничение бесплатного тарифа Render без перехода на платные серверы:
- **Проблема**: На бесплатном тарифе Render.com веб-сервисы засыпают (Spin-down) после 15 минут отсутствия входящих HTTP-запросов. В спящем режиме процесс приостанавливается, и боты с парсером перестают реагировать.
- **Решение через [UptimeRobot](https://uptimerobot.com)**:
  1. В бэкенд встроен легковесный HTTP-сервер, слушающий эндпоинт `GET /health` (и `GET /`). Он моментально возвращает статус `200 OK` и базовую телеметрию (аптайм, количество отслеживаемых источников) без создания нагрузки на CPU и оперативную память.
  2. В бесплатном сервисе мониторинга **UptimeRobot** настроен HTTP(s)-монитор с интервалом опроса раз в **5 минут**.
  3. Каждые 5 минут UptimeRobot обращается к эндпоинту `https://it-start-bot.onrender.com/health`.
  4. Render регистрирует регулярные входящие запросы и **не усыпляет контейнер**.
- **Результат**: Боты и парсер продолжают непрерывно функционировать **круглосуточно 24/7**, не требуя платной подписки на серверный хостинг.

## 9. Функциональные модули платформы

1. **Каталог вакансий и стажировок**: Лента актуальных позиций с поиском по технологиям, фильтрацией по 6 направлениям, формату занятости и локации, а также расчетом индекса готовности соискателя на основе его навыков.
2. **Интерактивные роадмапы**: Структурированные карты развития от базового фундамента (Core: сети, Event Loop, базы данных, архитектура) до практических инструментов конкретного стека с сохранением прогресса по темам и подтемам.
3. **Тренажёр вопросов к собеседованию**: База из 55+ детально разобранных вопросов с режимами флеш-карточек и самооценки («Знаю» / «Повторить») со скрытием правильного ответа.
4. **Центр подписок и уведомлений**: Управление персональными уведомлениями о новых вакансиях в Telegram и VK с выбором интересующих треков.

## 10. Отказоустойчивость

- **Многоуровневая изоляция сбоев**: Падение сетевого запроса к одному из каналов или карьерных сайтов не прерывает работу других источников и серверных ботов.
- **Автоматическое переподключение**: Циклы Long Polling для Telegram и ВКонтакте перехватывают сетевые ошибки, выполняют паузу и автоматически восстанавливают соединение.
- **Работа без внешних ключей**: При локальном тестировании или отсутствии токенов в переменных окружения боты переходят в демонстрационный режим, логируя события без аварийного завершения процесса.

## 11. Справочник команд запуска

```bash
# Режим локальной разработки фронтенда
npm run dev

# Продакшен-сборка фронтенда (TypeScript + Vite + postbuild)
npm run build

# Запуск тестов Vitest (все 45 тестов)
npm run test

# Проверка кода линтером Oxlint
npm run lint

# Запуск Telegram-бота и парсера вакансий
npm run bot

# Запуск ВКонтакте-бота
npm run bot:vk

# Запуск обоих ботов и парсера в едином процессе
npm run bot:all
```
