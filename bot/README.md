# Серверная часть ботов IT-Старт (Telegram & ВКонтакте)

Архитектура серверных ботов IT-Старт включает два взаимодействующих модуля на Node.js (ES Modules), подключенных к единой базе данных **Supabase** (`public.internships`, `public.tg_subscriptions`) и общей системе мониторинга карьерных сайтов и каналов работодателей:
1. **Telegram-бот:** `bot/bot.mjs` — работает по протоколу Long Polling (@IT_start_izh_bot) + HTTP Health Check & API сервер (порт 3000).
2. **ВКонтакте-бот:** `bot/vk_bot.mjs` — работает по Bots Long Poll API (сообщество ВКонтакте) с поддержкой интерактивных клавиатур и пуш-уведомлений.

---

## ⚡ Быстрый запуск ботов

Скрипты написаны на чистом Node.js (ES Modules) с использованием нативного `fetch` (не требуют внешних тяжелых зависимостей).

```bash
# 1. Запуск Telegram-бота и HTTP-сервера
TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН_ОТ_BOTFATHER" npm run bot

# 2. Запуск VK-бота сообщества ВКонтакте
VK_BOT_TOKEN="ВАШ_КЛЮЧ_ДОСТУПА_ГРУППЫ_VK" npm run bot:vk

# 3. Одновременный запуск обоих ботов (Telegram + VK)
TELEGRAM_BOT_TOKEN="ТОКЕН_TG" VK_BOT_TOKEN="ТОКЕН_VK" npm run bot:all
```

> **Примечание:** Если токены не указаны, оба бота автоматически переходят в безопасный демонстрационный режим (Fallback Mode) без падений и ошибок, позволяя тестировать команды и веб-интерфейс локально.

## 🔑 Подробная инструкция: Как получить токен в сообществе ВКонтакте

Для работы VK-бота требуется ключ доступа сообщества (VK Group Access Token):

1. **Создайте сообщество или откройте существующее:**
   - Перейдите в [vk.com/groups](https://vk.com/groups) и откройте ваше сообщество (вы должны иметь права Администратора).
2. **Создайте ключ доступа к API:**
   - В меню справа выберите **«Управление»** (шестеренка).
   - В левом меню перейдите в **«Работа с API»**.
   - Нажмите кнопку **«Создать ключ доступа»**.
   - Обязательно отметьте галочку: **«Разрешить приложению доступ к сообщениям сообщества»** (и при необходимости «к фотографиям сообщества»).
   - Подтвердите создание через SMS / VK ID и скопируйте сгенерированный ключ (начинается с `vk1.a...`).
3. **Включите сообщения сообщества:**
   - В левом меню перейдите в раздел **«Сообщения»**.
   - Переведите переключатель **«Сообщения сообщества»** в положение **«Включены»**.
4. **Активируйте возможности ботов:**
   - В разделе **«Сообщения»** перейдите во вкладку **«Настройки для бота»** (или «Боты»).
   - Установите **«Возможности ботов: Включены»**.
   - Отметьте галочку **«Добавлять кнопку "Начать"»**.
5. **Запустите бота:**
   ```bash
   VK_BOT_TOKEN="vk1.a.ВАШ_СКОПИРОВАННЫЙ_КЛЮЧ" npm run bot:vk
   ```

## 🤖 Возможности и команды VK-бота (`bot/vk_bot.mjs`)

- **«Начать» / `/start` / `Привет`** — приветствие, автоматическая подписка на обновления и постоянная клавиатура быстрого доступа.
- **«Стажировки» / `/vacancies`** — каталог актуальных стажировок с кнопками выбора направлений:
  - Frontend (React, Vue, Angular)
  - Backend (Python, Go, Java, Node.js)
  - Mobile (Android, iOS, Flutter)
  - Data Science & ML / AI
  - QA Тестирование (Auto & Manual)
  - DevOps & Cloud
- **«Компании» / `/companies`** — обзор ключевых работодателей (Холдинг Т1, СКБ Контур, Т-Банк, Directum, Яндекс, Ozon Tech, Сбер, Avito Tech, VK).
- **Прямой поиск по компании:** отправьте боту название («директум», «контур», «тбанк», «т1», «яндекс» и т.д.), и бот мгновенно выведет её открытые стажировки и стек.
- **«Роадмапы» / `/roadmaps`** — информация о картах компетенций со ссылкой на веб-приложение.
- **«Вопросы» / `/questions`** — тренажёр из 55+ вопросов к собеседованию и режим симуляции.
- **«Подписка» / `/subscribe`** — оформление подписки на мгновенные персональные уведомления о новых вакансиях в личные сообщения VK.
- **«Статус» / `/status`** — статус парсера, количество отслеживаемых сайтов и каналов, аптайм сервера.
- **«Помощь» / `/help`** — полная справка по всем командам и алиасам.
- **Кнопка «🚀 Открыть IT-Старт»** — переход в веб-приложение / VK Mini App.

## 🌐 Бесплатный деплой обоих ботов на Render.com (24/7)

1. Откройте панель управления [dashboard.render.com](https://dashboard.render.com/).
2. Нажмите **New +** -> **Web Service** и выберите репозиторий `oioiqp/it-start`.
3. Укажите параметры:
   - **Runtime:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `npm run bot:all`
   - **Instance Type:** `Free`
4. В разделе **Environment Variables** укажите:
   - `TELEGRAM_BOT_TOKEN` — токен от @BotFather
   - `VK_BOT_TOKEN` — ключ доступа сообщества ВКонтакте
5. Нажмите **Deploy Web Service**. Бот запустит и Telegram Long Polling, и VK Bots Long Poll одновременно на едином сервере!
